# 🚀 LinkiaEvent

**LinkiaEvent** es una plataforma de networking de alto nivel diseñada para maximizar las conexiones profesionales en eventos mediante una interfaz ágil de tipo swipe.

---

## 📋 Resumen del Proyecto
Esta aplicación permite a los asistentes a un evento:
1.  **Hacer Check-in** mediante un código de acceso único (sin necesidad de registros complejos).
2.  **Descubrir perfiles** relevantes y conectar mediante un sistema de deslizar (swipe).
3.  **Hacer Match** bidireccional cuando ambos perfiles muestran interés.
4.  **Chatear en tiempo real** para concretar reuniones o intercambiar ideas.

---

## 🛠 Stack Tecnológico
- **Frontend**: Next.js 16 (App Router) + React 19.
- **Backend / DB**: Supabase (PostgreSQL + Realtime + Edge Functions).
- **Estilos**: Tailwind CSS 4 + Framer Motion para animaciones premium.
- **Infraestructura**: Serverless (Edge Functions).

---

## 🚀 Inicio Rápido

1.  **Instalar dependencias**:
    ```bash
    npm install
    ```

2.  **Configurar entorno**:
    Asegúrate de tener las credenciales de Supabase en tu archivo `.env.local`.

3.  **Ejecutar en local**:
    ```bash
    npm run dev
    ```
    Visita `http://localhost:3000`.
